## Execution and review

Fresh Luna medium agents where available; no inherited conversation, no prior report access, no mid-run hints. Actual host capability inventory must be disclosed; browser absence is not simulated browser testing. No website mutation, login, submission, access-control bypass or rate abuse. Publicly exposed credentials or session identifiers, if encountered, are not to be used or republished.

Measure auditor-observed start and report completion, plus a parent dispatch-to-observed-completion upper bound when available. A last clock before the final response is not precise final-delivery timing. A report that validates after correction is not an unassisted first-pass success. Record limits, schema failures, missing/unsupported findings, question support and independently reproduced observations. No detection recall claim without an independently established denominator of defects.

The runtime revision keeps the v1.2 schema intact, reduces collector defaults for timed invocations to 5 pages/45 seconds, stops collection at 120 seconds, aims for report composition by 240 seconds and delivery by 280 seconds. These are instructions, not an externally enforced timeout.
