# Diverse-site runtime and generalization trial

## Conclusion

The broader test does **not** establish readiness for arbitrary websites. It exposed unsupported findings and an over-budget run. The runtime revision is a tested candidate, not a proven solution or a new submission-ready claim.

The user challenged the earlier sample's emphasis on well-maintained sites. Five different sites were selected before observing auditor results: a dense Norwegian retail catalogue, an Indian municipal portal, a regional English/Tamil university, a modern Indian storefront and a minimal investor-information site. Selection was purposive, not random; none should be assumed defective or healthy based on appearance or reputation. Model pretraining familiarity is unknown.

## Frozen candidate

Base commit `3f3eb64`, plus the runtime instructions fingerprinted in the [protocol](holdout-2026-09-10/protocol.md): timed collector 5 pages/45 seconds; stop evidence gathering by 120 seconds; report target 240 seconds; validation/delivery target 280 seconds. The v1.2 schema and evidence/safety gates were preserved. Duplicate narrative and default separate-ledger writing were reduced. No per-site instruction changes were made during this batch.

The full deterministic suite, including actual extracted-ZIP execution, passed on Python 3.12.14. This checks engineering behavior, not agent judgment or five-minute completion.

## What this establishes—and does not

This is evidence that harder sites can expose weaknesses the original sample missed. Passing JSON validation is not equivalent to correct detection. A time-budget instruction does not enforce the host's runtime. Zero fully accepted findings in a small review is not a population precision estimate, and the reviewer's few discovered misses are not a complete recall denominator.

The remaining three cases were not launched after the account usage-limit interruption. Resume them on the same frozen revision when capacity is available, then use new sites to evaluate any subsequent correction. Do not erase the failed outputs or tune to these exact domains. No claim is made that Adobe guarantees a browser or Python; missing browser capability necessarily leaves interactive checks unverified.
